# Journey Buddy

Create a prototype for an autism aid app with the following features:
1. Sensory aid tools 
2.progress tracker ( for them and parents) 
3.daily routine and schedule 
4. Reward system? 
5. AI for Personal journey where ai tells them how far have them come and how much progress they want to make or is making currently 
2 AI that teaches talking, ASL and AAC (This model can predict what the user will say on the base of their previous texts or mood)
